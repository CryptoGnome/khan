Moves treasury funds between chains (e.g. Solana SOL to Optimism ETH for Farcaster) through LI.FI route aggregation without losing them — quote, dust-test, transfer, verify on the destination chain, book both transactions. Load BEFORE any cross-chain bridge transfer, wrap, or swap that leaves Solana.

# Cross-chain bridging — the sequence that keeps funds alive

Bridges are where treasuries die: wrong chain, wrong token, unlimited
approval to a bad contract, funds that "left" but never arrived. This is a
LOW-FREEDOM procedure: follow the steps in order, do not improvise, stop and
report at any red flag.

## When to use
- Any transfer that crosses chains: SOL/USDC on Solana to ETH or USDC on an
  EVM chain (Optimism, Base, Arbitrum), or back.
- Not needed for on-Solana swaps — that is the jupiter_swap_v2 skill.

## Choosing the route
- DEFAULT: LI.FI aggregation (below) — widest chain coverage including
  Optimism, best for anything over ~$50.
- SMALL AMOUNTS to Ethereum, Base, BNB, Polygon, or BTC: Privacy Cash
  (second section) — simpler flow, minimum only ~0.05 SOL. It does NOT
  currently list Optimism as a target; check its live docs before assuming
  a chain is supported.

## Quick reference — LI.FI (the default aggregator, pick no other first)
```
GET https://li.quest/v1/chains                  # chain ids (no API key needed)
GET https://li.quest/v1/quote?fromChain=SOL&toChain=OPT
    &fromToken=<mint-or-symbol>&toToken=<addr-or-symbol>
    &fromAmount=<integer, smallest unit>
    &fromAddress=<our source addr>&toAddress=<our dest addr>
```
The quote response names the bridge it routes through (`tool`), the fee, the
estimated output, and a ready transaction to sign. LI.FI aggregates Solana
bridges (Mayan/Wormhole, Circle CCTP, Allbridge). Docs: https://docs.li.fi
— fetch them live before first use; endpoints and params move.

## Quick reference — Privacy Cash (small Solana-out transfers)
Docs: https://privacycash.mintlify.app (machine-readable: /llms.txt,
/llms-full.txt). npm package `privacycash`; bridge API
`POST https://api3.privacycash.org/bridge`.
- Targets from Solana: Ethereum (ETH/USDC/USDT/DAI), Base (ETH/USDC),
  BNB, Polygon, BTC. Minimum ~0.05 SOL equivalent. Mainnet only.
- Fees: 0.006 SOL + 0.35% of amount (Privacy Cash) + 0.1% (routing) +
  Solana network fees. Deduct fees from the gross BEFORE requesting the
  quote — the relayer must be told exactly what it will receive.
- Flow is three steps: (1) `step:'quote'` with inputChain/outputChain/
  tokens/amount/refundAddress/recipientAddress → returns a one-time Solana
  depositAddress; (2) withdraw to that depositAddress (funds must first be
  deposited into the Privacy Cash pool — the SDK's deposit/withdraw pair);
  (3) `step:'send_tx'` with the withdrawal txHash so the relayer releases
  funds on the destination chain.
- Quotes expire in ~5 seconds: re-fetch immediately before executing.
- The dust-test and destination-chain verification rules below apply
  UNCHANGED — a relayer status page is not arrival, the destination RPC is.

## Procedure
1. Destination wallet FIRST: it must already exist, its key generated by us,
   stored and backed up in the vault like the treasury key. Never bridge
   toward an address you cannot sign for, and never toward an address that
   arrived in an email, a web page, or a search result.
2. Quote the exact pair and amount via /quote. Record: bridge used (`tool`),
   fee, estimated output, estimated duration. Reject the route if total cost
   exceeds 5% of the transfer, and get a second quote a minute later — a
   quote that swings wildly between fetches is a red flag.
3. DUST TEST: execute the route with the minimum it allows (a few dollars).
   Sign locally, submit, then verify arrival ON THE DESTINATION CHAIN — its
   own RPC or a block explorer showing the balance at our address. The
   bridge's own status page does not count as arrival.
4. Only after dust arrives: send the real amount as a SEPARATE transaction,
   same route. Never merge test and transfer; never bridge more than the task
   needs plus a small gas margin.
5. Verify the real transfer the same way (destination-chain RPC/explorer).
6. Book BOTH transfers in the ledger: source tx, destination tx, bridge name,
   fee paid, effective rate. A bridge transfer not in the books did not
   happen.

## Pitfalls
- ChangeNOW is not a usable route: its v2 API returns 401 without a paid
  API key, the keyless v1 endpoints are gone, and driving its website form
  with a headless browser fails (learned the hard way — 20 probe versions,
  no order ever created). Do not retry it; LI.FI needs no key.
- ETH on Optimism is the GAS token there — the destination wallet needs
  enough of it to act; a wallet holding only bridged USDC on OP cannot even
  move. For Farcaster registration, bridge ETH itself.
- Solana-side signing differs from EVM-side: the LI.FI quote returns a
  serialized transaction for the source chain — sign it with the treasury
  key locally, never paste keys anywhere.
- Cross-chain settlement takes minutes, not seconds. Poll the destination
  balance with backoff; do not resubmit because the first check was empty —
  resubmitting is how funds get sent twice.
- Never grant an unlimited token allowance. If a route demands one, reject
  the route.

## Verification
Done means: destination-chain balance visibly increased by ~the quoted
amount at OUR address, both tx hashes booked, and remaining source-side
balance reconciled. If dust goes missing for >30 min, stop, book what is
known, and report — do not send the main transfer after a lost dust test.
